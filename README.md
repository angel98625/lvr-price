# 實價登錄行情

網址：https://angel98625.github.io/lvr-price/

選縣市、行政區，再選一樓／樓上層 × 買賣／租金或車位買賣、建物型態（含店面）、使用分區、交易日期、屋齡、坪數、房數，並可排除頂層、特殊交易、夾層、社宅等，馬上看到單價中位數、走勢圖、各區比較與成交明細。含地下室的交易不算行情，但列在明細。選 1～3 個行政區時，會把行情相近、地圖上相連的路段自動併成「行情分區」畫在地圖上，並塗滿整個行政區（路段座標在瀏覽器用 Esri 定位並記在裝置上）。

資料由 GitHub Actions（`.github/workflows/price-data.yml`）每月 2、12、22 日自動從內政部實價登錄網站下載最近 3 年資料，整理後放在 `price-data` 分支（每次覆蓋，不累積歷史；`claude/**` 開發分支的測試資料放 `price-data-dev`）。行政區界線來自 npm 套件 taiwan-atlas（內政部鄉鎮市區界線）。想立刻更新：到 Actions → 實價登錄行情資料更新 → Run workflow。

想把結果標在地圖上，可下載 Excel 後匯入 [實價登錄地圖](https://angel98625.github.io/lvr-map/)。
